# :simple-truenas: TrueNAS Deployment


**PowerBeacon** can be deployed on TrueNAS using the available app in the TrueNAS catalog. This is a convenient option for users who want to deploy PowerBeacon on their TrueNAS system without having to manually configure and run Docker containers.

See the [TrueNAS documentation](https://apps.truenas.com){:target="\_blank"} for more information on how to deploy and use apps on TrueNAS.

Also you can see **PowerBeacon** in the [TrueNAS app catalog](https://apps.truenas.com/catalog/powerbeacon_community/){:target="\_blank"}


!!! warning "Security Considerations"
    When deploying PowerBeacon on TrueNAS, ensure that you follow best practices for securing your TrueNAS system and the PowerBeacon application. This includes using strong passwords, enabling HTTPS, and keeping your system and applications up to date with security patches.
